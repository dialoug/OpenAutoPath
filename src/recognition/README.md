# 特征识别与几何缓存

`oap_recognition` 提供孔识别和三轴结构追踪，依赖分析模块，不依赖 UI 或刀路线程池。
应用层通过 `RecognitionRangeExecutor` 注入已有共享线程预算；没有执行器时同步串行执行。

## 几何计算规则

- 孔壁候选目前要求 OCCT 原生解析圆柱。非解析面的平面回归不会产生圆柱候选，
  因此没有原生圆柱时直接返回空孔结果，不构建主外表面缓存。
- 有孔候选时复用 `Model` 中已有且有限的精确面盒与参与实体的整体盒。
  缺失或非有限的面盒逐项回退 `AddOptimal`；整体范围不完整时对完整形状精确回退，
  不使用部分实体的包围盒替代完整范围。
- 两种缓存模式均对每个面进行一次有效平面分类。主外参考盒累加已有精确面盒，
  主外边界判定和后续追踪共享同一平面结果，避免再次求盒或曲面回归。
- 保留原平面回归、角度和距离容差。识别尺寸与边界不能直接换成样条控制点保守盒。
- `Full` 模式额外预计算边质心和邻接。范围任务全部完成后才能发布缓存；取消或异常
  丢弃部分结果。不新增独立线程池，不并行化有先后关系的追踪合并。

独立几何 API 在没有索引包围盒时仍需精确求盒。整体精确求盒失败后的面盒回退会合并
全部有效面，而不是只保留第一面。空索引整体盒的正常精确回退仍包含孤立边等几何。

## 回归与实际模型计时

`occt_recognition` 覆盖通孔、盲孔、多实体、缺失/非有限索引包围盒及无圆柱 NURBS。
`three_axis_recognition` 覆盖真实 B 样条平面/非平面、旧几何接口判定一致性、孤立边、
共享预算、取消/异常原子性，以及串行和并行完整识别输出一致性。

实际样件可使用应用加载后生成的匹配缓存目录，避免把 STEP 导入和索引耗时混入识别计时。
完整构建部署后在仓库根目录运行：

```powershell
$env:PATH = "$PWD/build/RelWithDebInfo/bin;$env:PATH"
./build/RelWithDebInfo/tests/oap_test_three_axis_recognition.exe `
  --cached-model "<应用cache目录>/<模型内容哈希>" `
  --snapshot "$PWD/build/recognition.snapshot"
```

输出分别报告孔识别与三轴识别耗时；快照覆盖孔几何、特征及三轴输出的全部字段，
对无序集合规范排序，可比较文本或 SHA-256。设置 `OAP_CAM_MAX_THREADS=1` 可验证单线程等价性。
`--skip-holes` 仅用于明确已知无孔样件的旧版本三轴基线采集，会在日志标记跳过；
正常验收不应使用此选项。

2026-11-08 本机 RelWithDebInfo 的 `rounded_relief.step`：135 面，其中 105 个 B 样条面、
0 个解析圆柱。旧孔缓存构建 157.18 秒、孔分类 1.23 秒；优化后完整孔入口 1.61 毫秒。
旧三轴阶段独立计时约 14.37–15.42 秒，优化后 463.79 毫秒。
