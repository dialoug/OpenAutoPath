## 1. 目标与边界

模块把根外线框及其固定轴加工面组转换为逐层外部清料与最终轮廓精修。完整结果必须保护成品材料，支持复杂层变截面、多刀余料和安全连接，并在保存/重开后确定性重建。

```text
Root outer wire 稳定引用
  -> ProfileRegion 与逐层真实材料外边界
  -> 外部清料/余料/最终精修
  -> 连接和完整装配安全验证
  -> Profile 中立程序与一等 IPW 节点
  -> Job 保存、重建、余量审计和输出
```

当前范围是固定刀轴 2.5D 外轮廓。任意三维修边、倒角/去毛刺、多轴侧铣和机床补偿认证另立模型，不得混入现有算法语义。

## 2. 当前实现基线

### 外轮廓自动方向规划（第一阶段）

生成入口提供“自动规划方向”（默认）、“全部方向”和指定装夹方向。
自动模式按同一实体分别处理，先按加工深度排序，再使用原自动选刀规则预筛刀具。
`ProfileDirectionPlanner` 对候选根外环构造棱柱包络，并以非破坏性 OCCT 布尔运算验证：
成品实体完全位于包络内、完整外侧壁属于成品边界、该实体其他来源的根面均落在包络表面。
只有全部检查通过，才由该来源覆盖其他外轮廓来源；不同实体不会合并。
等深候选保留应用层的稳定六面顺序，因此普通板状件优先 +Z。

首版支持完整特征深度、世界轴对齐方向、按单元包围盒毛坯，且所选刀轴方向无端面毛坯余量。
侧向开口、台阶、倒扣、内部独立根面、斜向包围盒余料、外部 STEP 毛坯、手动深度，
以及布尔失败/警告或无法证明覆盖的情况，均保留原有全部来源。
曲线根环的离散多边形若不能通过严格几何覆盖验证，也不精简方向。
本阶段不搜索全局最少装夹组合，不做翻面分段加工；预选方向后刀路生成或安全验证失败，
仍整批失败，不静默省略失败区域，也不绕过现有刀具装配检查。

规划与生成同处后台重任务，支持布尔阶段取消；失败或取消不提交 Job。
选中来源通过已有 Profile 工序定义保存，重开按这些定义恢复，不重新扩大为六方向。
验证覆盖 `profile_direction_planning` 的正反例，以及 `single_tool_workflow` 的方向映射、
原全部方向语义、取消和保存重开。完整构建及真实 STEP 验收结果记录在本次实施报告中。

## 3. 不可破坏的契约

1. `rootWireId` 必须是 `rootFaceId` 的真实 outer wire，不接受人工拼边或显示轮廓。
2. `sourceFaceIds`、`machiningFaceIds`、`terminalFaceIds` 和 `mainOuterFaceIds` 职责不能互换。
3. 成品实体用于保护材料；局部 `sectionShape` 只决定当前 Profile 的真实逐层边界。
4. 复杂降台/圆角外边界必须逐层使用最终实体截面，不能把根外环贯穿到底。
5. 外部清料只能发生在毛坯边界与累计成品包络之间。
6. 每个方向/深度组的多刀链中只有明确的末刀 `finishPass=true`；前序刀不得重复贴最终轮廓。
7. 同深直连必须使用当前层及上方累计保护包络，证明不足时退刀。
8. Job 保存稳定来源、参数和刀具/Setup 快照，不保存 `ProfileRegion`、loops 或 moves。
9. Profile 作为独立工序种类进入程序、Job 和 IPW，适配器只能作为迁移手段，不能永久抹去类型。
10. 取消、几何歧义、安全失败或无余料不发布半批次。

2026-11-09 选刀修复：按开口方向、伸达深度和单层刃长需求分组，各组独立执行
原有大刀/余料/精修规划，避免深侧面提前排除浅区域可用的小刀。组合结果保持
全局 `sourceRegionIndex` 和唯一工序 ID，候选计数统计“组 × 刀具”组合。各组顺序
生成并共用并行预算，所选范围内任一组不可达、失败或取消时不发布部分刀路。
桌面生成入口允许选择全部方向或单个装夹方向，显示区域数量及最大深度；成功
后替换外轮廓工序族，其他工序族保持不变。已识别但未选中的方向不会被当作已加工。

若最小候选刀的完整规划/安全校验失败，保留失败审计并尝试下一把较大候选刀。
更换末刀后必须重新评估带精修的阶段，不能复用粗加工缓存来充当精加工结果；
全部候选均失败才拒绝生成，回退成功会记录 `profile.final_tool_fallback` 警告。
本机 `cam_feature_test.stp` 与通用模拟刀库实测：-X 的 120 mm 伸达要求明确失败；
+Z 深度 20 mm 通过完整桌面工作流及 Job 捕获，使用 T1013/D12、T1009/D5，
生成 2 道工序，共 7398 个移动，安全和程序校验通过。此记录不替代其他模型验证。

## 5. R4 实施清单

### 5.1 一等 Profile IPW 后端

- 已完成：`MultiDexelStock` 接受中立 `FixedAxisToolpathView`，制造 IPW 的原生 Profile 分支直接使用它；
- 已完成：Profile 仿真公开接口仅返回借用视图，旧载体适配移至 workflow 的显式兼容桥；
- 待迁移：BRep 回退、场景和逐移动显示请求仍使用 `legacyProfileSimulationOperation()`；
- 检查点 backend ID、内容指纹、统计和诊断明确标识 Profile；
- 复用公共固定轴扫掠内核，但保留 Profile 的成品外侧、finish pass 和余料阶段语义；
- 对同一输入比较旧适配路径和新后端的体积、区间、余量、过切及内容指纹，差异超限不切换；
- 支持逐移动前缀回放，以便 Profile 在统一 IPW 时间线中与 Pocket/Hole 行为一致。

### 5.2 严格安全发布

- 对 Cut/Rapid/Plunge/Retract 和低位直连执行完整刀具装配连续扫掠；
- 切刃、总长、刀杆、刀柄或主轴尺寸缺失时，正式批次失败而非 Warning；
- 采样预算耗尽时不发布未经证明的工序；
- 验证指纹覆盖逐层材料边界、累计连接包络、刀具装配、余料前序刀径和父 IPW；
- 只有安全证据、余量审计、程序验证和 IPW 更新全部通过才提交 Job 结果。

### 5.3 R4 必须新增的测试

- 根外环简单直壁、圆角外边界、降台和不同深度截面；
- 低位直连在当前层安全但与上方台阶碰撞；
- 刀杆/刀柄/主轴跨越外轮廓凸台的反例；
- 大刀→小刀→精修三阶段余量，前两刀不得贴最终边界；
- Profile 原生/旧适配 IPW 等价、错误父键和取消；
- 无外部材料、毛坯边界不足和轮廓偏置坍缩；
- 保存—加载—重建后目标引用、finishPass、sequence 和验证指纹稳定。

## 6. R5/R6 后续重点

- 明确 Job 工序级参数快照，避免全局默认变化修改旧 Profile；
- 工序树支持刀具链、径向/轴向步距、最终余量和 finish pass 编辑，并展示下游失效；
- 后处理区分几何刀心路径与控制器半径补偿，第一版默认输出已补偿刀心，启用 G41/G42 前必须建模进退刀和控制器能力；
- 圆弧语义必须携带等价 fallback，并同时通过预览、验证、IPW 和后处理；
- 建立六面 Setup、复杂外边界和大型轮廓行程优化基准。
