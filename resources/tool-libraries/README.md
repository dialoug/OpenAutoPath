# 通用模拟测试刀库

`general-simulation.oaptl` 是项目原生刀库文件，可在刀库管理中导入，随后选择为活动刀库。名称为 **【模拟测试】通用毫米制刀库（281 把）**，固定库 ID 为 `simulation-general-mm-v1`。它使用合成参数，不包含机床现场刀库数据。本文件随程序内嵌，启动时若缺少该固定 ID 的刀库，会自动导入并保存，无需手动选择文件。已有模拟刀库的修改和有效的活动刀库选择会保留；首次启动时自动选中模拟刀库。删除模拟刀库后，下次启动会重新导入。用户刀库目录损坏时会报错并保留原文件，不会覆盖。程序不会扫描目录导入其他参数表。

| 类型 | 数量 | 直径（mm） | 虚拟刀号 |
| --- | ---: | --- | --- |
| 中心钻 | 9 | 0.5、0.8、1、2、3、4、6、8、10 | T1–T9 |
| 钻头 | 254 | 0.5、0.6、0.8；1–20 步长 0.1；20.5–40 步长 0.5；41–60 步长 1 | T101–T354 |
| 平底铣刀 | 18 | 0.5、0.8、1、1.5、2、2.5、3、4、5、6、8、10、12、16、20、25、32、40 | T1001–T1018 |

全部刀具分配了 T 号，可参与当前自动选刀。每个平底铣刀直径只保留一种刃长，避免自动选刀按直径去重时丢失长刃候选。本测试刀库覆盖上述三类刀具。雕刻加工支持刀库中的球头刀、平底刀和圆鼻刀，本库尚未提供球头刀和圆鼻刀样本。丝锥等未接入的类型不列入覆盖承诺。

孔、槽腔和外轮廓可在各自的统一参数页选择“活动刀库自动选刀”或“单刀”。单刀直接填写 T1–T9999、尺寸、转速和进给，无需创建刀库；孔支持钻头和平底铣刀，槽腔与外轮廓支持平底铣刀、球刀和圆鼻刀。单刀仍按识别几何自动规划并通过原有可达性、覆盖和安全检查，不提供人工孔段或手动策略覆盖。
孔单刀遵守现有工艺：通孔仍采用钻削，平面底盲孔和可铣的沉孔肩部可使用平底铣刀；选择铣刀不会强制把通孔改为铣削。
外轮廓单刀支持轮廓加工和外部清料：轮廓加工直接使用指定刀具生成并验证；外部清料沿用清料阶段规划，只使用该刀。
雕刻可选择专用刀库，也可直接填写球头、圆鼻或平底单刀。方向默认为六面，也可单独选择 +Z、-Z、+X、-X、+Y 或 -Y。
雕刻参数页可选择“仅精雕”或“从毛坯加工”。后者用同一把选定刀具从项目毛坯保守包络分层开粗再精雕；分层最大切深不能超过刃长，开粗余量不能超过最大切深。该模式不按前序 IPW 精确残料优化选刀或裁剪刀路。
选择单刀后只使用该刀，尺寸不适合、参数无效或不可达时明确报错，不回退到活动刀库。正式工序保存完整刀具快照；单刀控制器不依赖刀库，重开项目仍可再生成。各类单刀配置不会改动活动刀库；深度、余量、步距等生成参数仍可调整。

## 合成参数

尺寸单位为 mm，进给为 mm/min，转速为 rpm。中心钻刃长 `max(3, 2D)`，钻头刃长 `min(200, 8D)`，平底铣刀刃长 `max(5, min(80, 5D))`，整体长度为刃长加 30。小直径铣刀采用模拟长刃几何，最小刃长 5 mm，不代表实物刀具的刚性或加工能力。中心钻尖角 90°，钻头尖角 118°，铣刀圆角半径为 0。刀杆直径 `max(6, D)`，刀柄直径 `max(32, 刀杆直径 + 12)`、长度 40，主轴包络直径 `max(80, 刀柄直径 + 10)`、长度 80。

钻削 S3000、垂直 F100；铣削 S6000、水平 F600、垂直 F150；水平/垂直快移 3000/1500，钻孔啄深 `min(5, D)`，钻孔循环自动，冷却关闭。这些数值用于驱动模拟，不按材料或实际刀具选定。

## 适用范围与限制

主要用于测试常见毫米制孔、槽腔、平面及外轮廓的识别后选刀和刀路。小直径铣刀补充窄槽及角部清根，大直径铣刀用于较大区域清料。刀具的刃长、整体长度和装夹包络均有明确值，仍受实际深度、可达性及碰撞检查限制。

刀库不能使任意 STEP 文件自动可加工：非整档精密孔、深孔、微细结构、倒扣、复杂曲面、螺纹及多轴加工可能需要额外刀具或尚未实现的策略；孔槽等特征加工还必须通过当前特征识别；雕刻直接使用完整模型，无需孔槽识别。没有基于真实 STEP 样本集得出的“多数文件成功率”。

**仅供软件模拟测试。** 虚拟刀号并非实际机床刀位，281 把工具也不代表真实换刀容量。合成的几何、装夹、转速和进给未经实机验证；真实加工需要另建与现场工具、材料和机床相符的刀库。本库标记与名称是提示，程序目前不会据此禁止导出 NC。

## 重新生成

在项目根目录运行：

```powershell
./tools/New-SimulationToolLibrary.ps1
```

可通过 `-OutputPath` 指定输出文件。生成过程只写刀库文件，不修改活动刀库、系统设置或已有刀库。

## 本次验证（2026-11-07）

使用当前项目已构建的 C++ 库调用真实存储和加工 API，完成以下检查：

- `ToolLibraryStorage` 原生加载、序列化往返一致；281 把刀具均通过库校验、装配字段检查及已分配刀具上下文转换。
- `HoleToolSelectionPlanner` 对 254 种钻头直径逐一选择对应钻头，无跳过孔。
- `HoleAutomaticToolpath` 对 D0.5、1、3.3、6.8、10、20、32、60 的合成通孔生成刀路，结构验证通过，去料覆盖审计为 8/8。
- `PocketAutomaticToolpath` 对深 2 mm 的 L 形槽腔及宽 7 mm 的槽生成刀路，选出 4 个铣削阶段并通过验证。
- `ProfileAutomaticToolpath` 对深 2 mm 的 L 形外轮廓执行外部清料及精加工，通过验证。
- 通过 `ToolAssetCatalog` 加入本机目录，再读取确认新库的 281 个已分配刀位；保留原有刀库及活动刀库设置。

上述加工测试从合成的已识别特征输入开始，不包含真实 STEP 导入/识别成功率统计，也不等于实机安全认证。

球刀半径由直径的一半推导；圆鼻刀需填写大于零且小于刀具半径的圆角，刃长必须覆盖球头或圆角高度。球刀、圆鼻刀沿用分层铣削，可能在槽底、根部留下余料；IPW 按实际刀具轮廓去料，不表示已经加工成平底。自动选刀在同直径候选中优先较小圆角，再按 T 号排序；用户可通过单刀明确指定刀型。圆角刀之后的阶段不使用仅凭前刀直径计算的余料裁剪，避免遗漏底部余料。普通钻头暂不参与槽腔或外轮廓横向铣削。
