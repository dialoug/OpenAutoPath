# Qt standard-control translations

`qtbase_zh_CN.ts` is the unmodified Qt 6.11.1 translation source from [qt/qttranslations](https://github.com/qt/qttranslations/blob/v6.11.1/translations/qtbase_zh_CN.ts). It is embedded and read with QXmlStreamReader at startup; Qt Linguist tools are not required.

Source: https://github.com/qt/qttranslations/tree/v6.11.1

To replace the translation, edit this TS source and rebuild the executable. The application contains no modified Qt code. Translation selection is context-specific and respects disambiguation; unfinished messages retain Qt's source fallback.
